ZIP으로 직접 설치하기
  1. 설치 ZIP을 다운로드하고 압축을 풉니다.
  2. Chrome 주소창에 chrome://extensions를 입력하고 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다 버튼을 누르고, 압축을 푼 폴더를 선택합니다. manifest.json이 바로 들어 있는 폴더입니다.
  4. PokéSurvivor를 열거나 새로고침하면 한국어가 자동으로 적용됩니다.

설치 폴더는 그대로 보관하세요. ZIP 설치본은 새 ZIP으로 파일을 덮어쓴 뒤 확장 프로그램과 게임을 새로고침해 업데이트합니다.

ZIP 설치본에서 스토어 설치본으로 옮길 때는 기존 확장을 끄세요. 두 설치본을 동시에 켜지 마세요.

언어 바꾸기

게임의 설정 → 그래픽 → 언어에서 한국어 또는 다른 언어를 선택합니다. 언어를 바꾸면 게임이 새로고침됩니다.

업데이트

스토어 설치본은 승인된 버전을 Chrome이 자동으로 업데이트합니다. ZIP 설치본은 새 ZIP으로 파일을 교체해야 합니다. 게임을 이미 열어 두었다면 새로고침하세요.

같은 LAN에서 멀티플레이 연결이 느린가요?

Windows 방화벽이 Chrome UDP 수신을 막는 경우, Windows LAN 도구로 신뢰하는 CIDR을 허용할 수 있습니다. 압축 해제 후 README를 읽고 관리자 권한으로 실행하세요. 추천 대역과 허용 범위를 확인한 뒤 YES를 입력해야 적용됩니다.

모든 네트워크 프로필에 남는 Chrome 규칙이며, Wi-Fi 이름이나 게임 사이트에 한정되지 않습니다. 양쪽 PC에서 설정 후 게임의 설정 → 네트워크 → P2P 직접 연결을 켜고 재접속하세요. 도구의 2번 메뉴에서 CIDR 규칙을 삭제할 수 있습니다.
