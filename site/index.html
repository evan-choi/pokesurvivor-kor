포케서바이버
한글패치

메뉴와 기술 설명을 한국어로 바꾸는 Chrome 확장 프로그램입니다. 설치하면 게임 설정에 한국어 버튼이 생깁니다.

한글패치 다운로드설치 방법

v{{VERSION}} · Chrome 119 이상 · 무료 · 비공식 팬 번역

메뉴와 전투 문구

설정, 도감, 강화, 미션을 번역했습니다. 플레이 중 나타나는 기술 설명과 전투 문구에도 적용됩니다.

포켓몬과 기술 이름

PokéAPI의 한국어 데이터를 참고했습니다. 포켓몬 이름과 별칭 1,041개를 포함합니다.

글꼴과 화면 정렬

한글에 맞춰 글꼴, 줄 간격, 버튼 크기를 조정했습니다. 원래 언어로 언제든 돌아갈 수 있습니다.

설치 방법

Chrome 웹 스토어에는 등록되지 않았습니다. ZIP 파일을 내려받아 직접 설치합니다.

  1. ZIP 압축 풀기

    한글패치 ZIP을 내려받아 압축을 풉니다. 설치한 뒤에도 이 폴더를 보관하세요.

  2. 개발자 모드 켜기

    Chrome 주소창에 chrome://extensions를 입력하고 오른쪽 위의 개발자 모드를 켭니다.

  3. 확장 프로그램 불러오기

    압축해제된 확장 프로그램을 로드합니다 버튼을 누릅니다. 압축을 푼 폴더 중 manifest.json이 바로 들어 있는 폴더를 선택하세요.

  4. 게임 새로고침하기

    PokeSurvivor를 열거나 새로고침합니다. 한국어는 처음부터 켜져 있습니다. 언어는 설정 → 그래픽 → 언어에서 바꿉니다.

GitHub의 Code → Download ZIP으로 소스 코드를 받았다면 그 안의 extension/ 폴더를 선택하세요. 설치용 ZIP과 폴더 구조가 다릅니다.

설치 전에 확인하세요

공식 한국어판인가요?

개인이 만든 비공식 팬 번역입니다. 원본 게임 제작자나 Pokémon 권리자가 제공하는 확장 프로그램은 아닙니다.

게임 저장 데이터가 바뀌나요?

이 확장 프로그램은 화면의 문구와 글꼴을 바꿉니다. 계정, 저장 데이터, 점수는 수정하지 않습니다. 번역은 기기 안에서 처리하며 외부 번역 서비스로 보내지 않습니다.

일부 문구가 원문으로 보여요.

게임 바깥의 사이트 안내, 채팅, 닉네임과 일부 글자 애니메이션은 번역하지 않습니다. 게임이 업데이트되면 새 문구가 원문으로 남을 수도 있습니다. 화면과 문구를 알려주시면 수정에 도움이 됩니다.

업데이트는 어떻게 하나요?

새 ZIP을 받아 설치한 폴더의 파일을 교체합니다. chrome://extensions에서 확장 프로그램의 새로고침 버튼을 누른 뒤 게임도 새로고침하세요.

번역 제보 · 작동 오류 제보
