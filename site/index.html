PokeSurvivor 한국어 모드 English

PokeSurvivor 한글패치

메뉴, 포켓몬 이름, 기술 설명을 한국어로 바꾸는 비공식 Chrome 확장 프로그램입니다.

다운로드게임 열기

설치

  1. 다운로드한 ZIP 파일의 압축을 풉니다.
  2. Chrome 주소창에 chrome://extensions를 입력하고 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다 버튼을 누르고, 압축을 푼 폴더를 선택합니다. manifest.json이 바로 들어 있는 폴더입니다.
  4. PokeSurvivor를 열거나 새로고침하면 한국어가 적용됩니다.

설치 후에도 이 폴더는 그대로 보관하세요.

언어 바꾸기

게임의 설정 → 그래픽 → 언어에서 English 또는 Español을 선택하면 원래 언어로 돌아갑니다. Chrome의 확장 프로그램 아이콘에서도 한국어를 켜고 끌 수 있습니다.

업데이트

새 ZIP을 받아 기존 폴더의 파일을 교체합니다. chrome://extensions에서 확장 프로그램을 새로고침한 뒤 게임도 새로고침하세요.
