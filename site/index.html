PokeSurvivor
한글패치

메뉴, 포켓몬 이름, 기술 설명을 한국어로 바꾸는 Chrome 확장 프로그램입니다.

한글패치 다운로드설치 방법

v{{VERSION}} · Chrome 119 이상 · 무료 · 비공식 팬 번역

메뉴와 전투

설정, 도감, 강화, 미션과 전투 중 표시되는 문구를 번역합니다.

언어 전환

게임 설정이나 Chrome의 확장 프로그램 아이콘에서 한국어를 켜고 끕니다.

폰트와 배치

한글에 맞춰 폰트, 줄 간격과 버튼 크기를 조정했습니다.

설치 방법

ZIP 파일을 내려받아 Chrome에 직접 설치합니다.

  1. ZIP 압축 풀기

    한글패치 ZIP을 내려받아 압축을 풉니다. 설치한 뒤에도 이 폴더를 보관하세요.

  2. 개발자 모드 켜기

    Chrome 주소창에 chrome://extensions를 입력하고 오른쪽 위의 개발자 모드를 켭니다.

  3. 확장 프로그램 불러오기

    압축해제된 확장 프로그램을 로드합니다 버튼을 누릅니다. 압축을 푼 폴더 중 manifest.json이 바로 들어 있는 폴더를 선택하세요.

  4. 게임 새로고침하기

    PokeSurvivor를 열거나 새로고침합니다. 설치하면 한국어가 켜집니다. 언어는 설정 → 그래픽 → 언어에서 바꿉니다.

GitHub의 Code → Download ZIP으로 소스 코드를 받았다면 그 안의 extension/ 폴더를 선택하세요.

사용 안내

게임 저장 데이터가 바뀌나요?

게임 계정, 저장 데이터, 점수는 바꾸지 않습니다.

일부 문구가 원문으로 보여요.

게임 바깥의 사이트, 채팅, 닉네임과 일부 보스 등장 연출은 번역하지 않습니다. 게임 업데이트로 새 문구가 추가되면 원문으로 남을 수 있습니다. 번역이 빠졌다면 아래 링크로 화면과 문구를 알려주세요.

업데이트는 어떻게 하나요?

새 ZIP을 받아 설치한 폴더의 파일을 교체합니다. chrome://extensions에서 확장 프로그램의 새로고침 버튼을 누른 뒤 게임도 새로고침하세요.
