Install manually from ZIP
  1. Download and extract the installation ZIP.
  2. Open chrome://extensions in Chrome and turn on Developer mode.
  3. Click Load unpacked and select the extracted folder that contains manifest.json directly inside it.
  4. Open or reload PokéSurvivor. Korean is applied automatically.

Keep the installed folder in place. To update a ZIP installation, replace its files with the latest ZIP, then reload the extension and game.

When moving from ZIP to the store version, disable the old extension. Do not run both installations together.

Change language

Choose Korean or another language under Settings → Graphics → Language. Changing the language reloads the game.

Update

Chrome automatically delivers approved updates to store installations. ZIP installations require replacing files with the latest ZIP. Reload any open game tab after an update.

Slow multiplayer on the same LAN?

If Windows blocks inbound Chrome UDP, the optional Windows LAN helper can allow a trusted CIDR. Extract it, read the README, and run as administrator. Review the suggested range and rule scope, then type YES to apply.

The persistent Chrome rule applies to all network profiles, not a specific Wi-Fi name or game site. On both PCs enable Settings → Network → Direct P2P connection in the game and rejoin. Choose menu option 2 in the helper to remove its CIDR rules.
