Korean patch

This Chrome extension translates menus and move descriptions into Korean. Installing it adds a Korean language button to the game settings.

Menus and battle text

Settings, the Pokédex, upgrades, and missions are translated. The patch also covers move descriptions and text shown during battles.

Pokémon and move names

Pokémon and move names are displayed in Korean.

Fonts and layout

Fonts, line spacing, and button sizes are adjusted for Korean text. You can switch back to the original language at any time.

How to install

The extension is not listed in the Chrome Web Store. Install it from the ZIP file.

  1. Extract the ZIP

    Download the patch ZIP and extract it. Keep the folder after installation.

  2. Turn on Developer mode

    Enter chrome://extensions in the Chrome address bar, then turn on Developer mode in the top right.

  3. Load the extension

    Click Load unpacked. Select the extracted folder that contains manifest.json directly inside it.

  4. Reload the game

    Open or reload PokeSurvivor. Korean is enabled by default. Change the language under 설정 → 그래픽 → 언어 (Settings → Graphics → Language).

If you used Code → Download ZIP on GitHub to get the source code, select the extension/ folder inside it. Its folder structure differs from the installation ZIP.

Before you install

Is this an official Korean version?

This is an unofficial fan translation made by an individual. The extension is not provided by the original game creator or Pokémon rights holders.

Does it change my save data?

The extension changes text and fonts on screen. It does not modify accounts, save data, or scores.

Why is some text still in the original language?

The patch does not translate the surrounding website, chat messages, player names, or some animated text. Game updates may also introduce untranslated text. Reporting the screen and the text helps us correct it.

How do I update?

Download the new ZIP and replace the files in the installed folder. Click the extension's reload button at chrome://extensions, then reload the game.
