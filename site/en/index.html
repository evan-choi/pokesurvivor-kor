How to install

Download the ZIP and load it in Chrome.

  1. Extract the ZIP

    Download the patch ZIP and extract it. Keep the folder after installation.

  2. Turn on Developer mode

    Enter chrome://extensions in the Chrome address bar, then turn on Developer mode in the top right.

  3. Load the extension

    Click Load unpacked. Select the extracted folder that contains manifest.json directly inside it.

  4. Reload the game

    Open or reload PokeSurvivor. Korean is enabled by default. Change the language under 설정 → 그래픽 → 언어 (Settings → Graphics → Language).

If you used Code → Download ZIP on GitHub to get the source code, select the extension/ folder inside it.

Using the patch

Does it change my save data?

The extension does not change game accounts, save data, or scores.

Why is some text still in the original language?

The surrounding website, chat messages, player names, and some boss introductions remain untranslated. Game updates can also add new text. Use the link below to report missing translations with the screen and text.

How do I update?

Download the new ZIP and replace the files in the installed folder. Click the extension's reload button at chrome://extensions, then reload the game.
