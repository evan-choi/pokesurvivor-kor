PokeSurvivor Korean Patch

An unofficial Chrome extension that translates menus, Pokémon names, and move descriptions into Korean.

DownloadOpen game

Install

  1. Extract the downloaded ZIP file.
  2. Open chrome://extensions in Chrome and turn on Developer mode.
  3. Click Load unpacked and select the extracted folder that contains manifest.json directly inside it.
  4. Open or reload PokeSurvivor. Korean is enabled automatically.

Keep the installed folder in place.

Change language

Choose English or Español under 설정 → 그래픽 → 언어 (Settings → Graphics → Language) to restore the original language. You can also turn Korean on or off from the extension icon in Chrome.

Update

Download the new ZIP and replace the files in the installed folder. Reload the extension at chrome://extensions, then reload the game.
