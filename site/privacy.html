개인정보 처리 안내

적용 버전: 0.2.23부터 · 개정일: 2026년 11월 9일 · 개발자: Evan Choi

브라우저 안에서 사용하는 정보

게임 화면의 문구를 읽어 번역하고, 기술·도구 설명과 화면 표시를 조절합니다. 안내문에 포함된 플레이어 닉네임은 원문 그대로 표시합니다. 현재 열린 PokéSurvivor 게임 탭의 주소와 최근 사용 시점을 확인해 보유 목록을 가져올 탭을 선택합니다. 브라우저 전체 방문 기록은 조회하지 않습니다.

보유 목록은 게임이 현재 불러온 데이터에서 보유 여부가 있는 포켓몬 번호만 읽습니다. 계정 ID, 로그인 상태, 세션 식별자, 비밀번호, 인증 토큰을 조회하지 않으며 저장 파일도 직접 읽지 않습니다. 포켓몬 번호는 팝업을 표시하는 동안 사용하고 따로 저장하지 않습니다. 기술·도구 설명을 표시할 때는 게임 화면 안의 현재 커서 위치를 잠시 참조하며, 이동 이력을 기록하거나 전송하지 않습니다. 별도의 사용자 프로필이나 분석 기록을 만들지 않습니다.

저장과 외부 요청

언어·연결·이펙트 설정은 브라우저에 저장합니다. 공개 포켓몬 티어 정보는 하루 동안 캐시하고, 갱신 실패 시 마지막 캐시를 표시할 수 있습니다. 확장을 삭제하면 확장 저장소의 설정과 캐시는 삭제됩니다. 게임 사이트 저장소에 남은 설정은 해당 사이트 데이터 삭제로 지울 수 있습니다. 사이트 데이터를 삭제하면 로컬 게임 저장에도 영향을 줄 수 있습니다.

티어 정보는 pokesurvivor.net에서, 포켓몬 이미지는 raw.githubusercontent.com의 PokéAPI 자료에서 HTTPS로 불러옵니다. 이미지 요청 주소에는 표시할 포켓몬 번호가 포함되며, 해당 서버는 일반 웹 요청과 같이 IP 주소 등 접속 정보를 받을 수 있습니다. P2P 직접 연결 옵션은 게임의 WebRTC 직접 연결을 허용하며 연결 상대에게 네트워크 주소가 노출될 수 있습니다. GPS 등으로 위치를 조회하거나 IP로 위치를 추정하지 않습니다. 게임 자체의 계정·멀티플레이 통신은 게임 서비스가 처리합니다.

사용 목적과 문의

정보는 한국어 번역, 게임 표시 개선, 보유 목록 및 연결 기능 제공에만 사용합니다. 광고·판매·신용 평가에 사용하지 않으며, 별도의 분석이나 사용자 추적 서버를 운영하지 않습니다. Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용 요건을 준수합니다.

문의 및 변경 안내: GitHub 저장소. 공개 문의에는 비밀번호나 계정 저장 데이터를 첨부하지 마세요.

이전 버전 안내

이전 0.2.22 버전에서는 보유 목록을 찾기 위해 게임 계정 ID 또는 로컬 세션 식별자를 참조하고 해당 계정의 브라우저 저장 데이터를 읽었습니다. 이 정보도 개발자 서버로 전송하거나 별도로 보관하지 않았습니다. 위의 접근 범위 축소는 0.2.23 이상으로 업데이트하고 게임을 새로고침한 뒤 적용됩니다.

Privacy summary

Version 0.2.22 used a game account ID or local session identifier to find the corresponding saved collection in browser storage. These identifiers were not sent to a developer server or retained separately. Update to 0.2.23 or later and reload the game to use the reduced-access collection reader.

For version 0.2.23 and later. The extension translates game page content, preserving player nicknames in notices. It checks the URL and last access time of open PokéSurvivor tabs to choose a game tab; it does not query browser-wide browsing history. Collection rankings use only owned species numbers from the data currently loaded by the game, without querying account IDs, login status, session identifiers, passwords, authentication tokens, or saved-game files. The numbers are used while displaying the popup and are not stored separately. Cursor position is used temporarily for tooltips; movement history is not recorded or transmitted. No separate user profile or analytics log is created.

Preferences are stored locally and public tier data is cached. Rankings come from pokesurvivor.net and images from PokéAPI files on raw.githubusercontent.com over HTTPS. Image URLs include species numbers, and these servers receive normal request information such as IP addresses. P2P connections may expose network addresses to game peers. The extension does not request GPS location or infer location from IP addresses. It does not send account data or activity logs to a developer server. Game account and multiplayer communications are handled by the game service. Data is used only for the stated features, not advertising, sale, or credit decisions, in compliance with the Chrome Web Store Limited Use requirements. Contact: the GitHub repository linked above.
