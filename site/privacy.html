브라우저 안에서 사용하는 정보

게임 화면의 문구를 읽어 번역하고, 기술·도구 설명과 화면 표시를 조절합니다. 게임 탭이 열려 있는지 확인해 확장 팝업의 기능을 표시합니다. 보유 포켓몬을 보여 줄 때는 게임의 로그인 상태와 계정 식별자 또는 저장된 세션 식별자를 참조하여 해당 계정의 로컬 저장 데이터에서 포켓몬 번호를 읽습니다. 로그인 비밀번호를 요청하지 않습니다.

이 정보는 브라우저 안에서 처리하며 게임 계정 식별자, 세션 식별자와 전체 저장 데이터를 개발자 서버로 전송하거나 별도로 보관하지 않습니다. 보유 목록은 팝업을 표시하는 동안 사용합니다. 기술·도구 설명을 표시할 때는 게임 화면 안의 커서 위치를 잠시 참조하며, 이동 이력을 기록하거나 전송하지 않습니다.

저장과 외부 요청

언어·연결·이펙트 설정은 브라우저에 저장합니다. 공개 포켓몬 티어 정보는 하루 동안 캐시하고, 갱신 실패 시 마지막 캐시를 표시할 수 있습니다. 확장을 삭제하면 확장 저장소의 설정과 캐시는 삭제됩니다. 게임 사이트 저장소에 남은 설정은 해당 사이트 데이터 삭제로 지울 수 있습니다. 사이트 데이터를 삭제하면 로컬 게임 저장에도 영향을 줄 수 있습니다.

티어 정보는 pokesurvivor.net에서, 포켓몬 이미지는 raw.githubusercontent.com의 PokéAPI 자료에서 HTTPS로 불러옵니다. 이미지 요청 주소에는 표시할 포켓몬 번호가 포함되며, 해당 서버는 일반 웹 요청과 같이 IP 주소 등 접속 정보를 받을 수 있습니다. LAN 연결 옵션은 게임의 WebRTC 직접 연결을 허용하며 연결 상대에게 네트워크 주소가 노출될 수 있습니다. 게임 자체의 계정·멀티플레이 통신은 게임 서비스가 처리합니다.

사용 목적과 문의

정보는 한국어 번역, 게임 표시 개선, 보유 목록 및 연결 기능 제공에만 사용합니다. 광고·판매·신용 평가에 사용하지 않으며, 별도의 분석이나 사용자 추적 서버를 운영하지 않습니다. Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용 요건을 준수합니다.

문의 및 변경 안내: GitHub 저장소. 공개 문의에는 비밀번호나 계정 저장 데이터를 첨부하지 마세요.

Privacy summary

The extension processes game page content, open game tab information, login/account or session identifiers, and owned Pokémon numbers locally to provide translation, display controls, and collection rankings. It does not request passwords or send account identifiers, session identifiers, or full game saves to a developer server. Cursor position within the game is used temporarily for tooltips; movement history is not recorded or transmitted. Preferences are stored locally; public tier data is cached. Rankings are fetched from pokesurvivor.net and Pokémon images from PokéAPI files on raw.githubusercontent.com over HTTPS. Image URLs include species numbers, and these servers receive normal request information such as IP addresses. Enabling direct WebRTC connections may expose network addresses to game peers. Data is used only for the stated features, not advertising, sale, or credit decisions, in compliance with the Chrome Web Store Limited Use requirements. Contact: the GitHub repository linked above. Effective November 7, 2026.
