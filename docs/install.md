# PokéSurvivor 한국어 모드 설치

[설치 페이지](https://evan-choi.github.io/pokesurvivor-kor/#install)에서 현재 제공되는 설치 방법을 확인하세요. 스토어 설치본은 Chrome이 자동 업데이트하며, 아래는 ZIP 직접 설치 방법입니다. 스토어 설치본으로 옮길 때는 기존 확장을 꺼서 중복 실행을 피하세요.

1. 설치 ZIP의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 버튼을 누릅니다.
5. `manifest.json`이 바로 들어 있는 폴더를 선택합니다.
6. [게임 페이지](https://pokesurvivor.com/)를 열거나 새로고침합니다.

설치 ZIP은 압축을 풀어 생긴 폴더 자체를 선택합니다. GitHub의 **Code → Download ZIP**으로 저장소를 받았다면 그 안의 `extension/` 폴더를 선택합니다.

처음 설치하면 한국어 모드가 켜집니다. 게임의 **Settings → Graphics → Language**에서 **한국어**를 선택하세요. 언어는 게임 설정에서 변경합니다.

## 전투 HUD 크기

게임 왼쪽 위의 포켓몬 이름·레벨·HP·버프는 기본 크기의 **1.5배**로 표시합니다. 파티원 HP는 겹치지 않도록 아래로 이동하며, 타이머와 기술 슬롯 크기는 유지합니다. 언어 설정과 관계없이 적용됩니다. 업데이트 후 확장 프로그램과 게임을 모두 새로고침하세요.

## 기술 설명

전투 화면 아래의 기술 슬롯에 마우스를 올리면 기술 설명이 표시됩니다. 연계 기술은 첫 기술을 맨 아래에 두고 위로 쌓으며, 진화한 기술은 추가 효과를 함께 표시합니다. 설명창은 마우스 클릭을 가로채지 않습니다.

현재 게임의 기술 103종을 지원합니다. 게임 업데이트로 기술이 추가되거나 설명·HUD 구조가 바뀌면 확장 프로그램도 업데이트가 필요할 수 있습니다.

## P2P 직접 연결

멀티플레이에서 게임 **설정 → 네트워크 → P2P 직접 연결**을 켜면 중계 전용 제한을 풀어 직접 연결도 허용합니다. 기본값은 꺼짐이며, 켜도 TURN 서버를 대체 경로로 유지합니다. 양쪽 PC에서 옵션을 켠 뒤 방에 다시 참가하세요. 이미 연결된 게임을 끊거나 새로고침하지 않으며, 다음에 만드는 연결부터 적용합니다.

공유기의 기기 간 통신 차단이나 방화벽에 따라 같은 공유기에서도 중계 서버로 연결될 수 있으며, 방장의 처리 지연은 이 옵션으로 해결되지 않습니다.

Radmin VPN 같은 가상 LAN에서도 Chrome이 해당 경로를 선택하면 사용할 수 있지만, 이 옵션은 특정 VPN 사용을 강제하지 않습니다. VPN 자체는 중계를 사용할 수 있습니다. Radmin의 `Relay/TCP` 여부는 Radmin에서 별도로 확인해야 합니다. 가상 LAN 환경에서의 실제 동작은 아직 검증하지 않았습니다.

### Windows 방화벽에서 LAN 대역 허용

같은 공유기에서도 방화벽의 Chrome UDP 차단 때문에 TURN을 사용할 수 있습니다. 이 경우 설치 ZIP의 `windows-lan/` 폴더 또는 [별도 LAN 도구 ZIP](https://evan-choi.github.io/pokesurvivor-kor/downloads/pokesurvivor-lan-helper.zip)을 사용합니다. 확장 프로그램이 도구를 자동 실행하지 않습니다.

1. 양쪽 PC에서 Chrome을 실행한 뒤, 도구의 `run-as-administrator.cmd`를 우클릭 → **관리자 권한으로 실행**합니다.
2. `1`을 선택하고 추천된 대역을 확인합니다. 맞으면 Enter, 다르면 자신의 CIDR(예: `192.168.0.0/24`)을 입력합니다. 한 PC만 허용하려면 그 IP에 `/32`를 붙입니다.
3. Chrome 경로·주소 범위·포트를 확인하고 `YES`를 입력해야 규칙이 추가됩니다.
4. 양쪽에서 게임 **설정 → 네트워크 → P2P 직접 연결**을 켜고 방에 재접속합니다.

규칙은 Chrome의 인바운드 UDP와 Windows 동적 포트 범위에만 적용됩니다. **모든 Windows 네트워크 프로필에서 유지되며, Wi-Fi 이름이나 게임 사이트에 한정되지 않습니다.** 입력 범위의 다른 기기도 Chrome에 접근할 수 있으므로 신뢰하는 대역만 허용하세요. Radmin의 `26.0.0.0/8`은 특정 그룹에 한정되지 않으므로 상대 주소 `/32`를 권장합니다. IPv6는 지원하지 않습니다.

되돌리려면 다시 실행해 `2`를 선택하고 목록 확인 후 `DELETE`를 입력합니다. 이 도구의 CIDR 규칙만 삭제하며 이전 PC 한 대 전용 규칙은 유지합니다. 공유기 포트포워딩이나 방화벽 전체 설정은 바꾸지 않습니다. 조직 정책·명시적 차단·공유기 기기 격리가 있으면 별도 조치가 필요할 수 있습니다. 자세한 범위와 사용법은 도구의 `README.md`에 있습니다.

## 업데이트와 문제 해결

설치한 폴더는 이동하거나 삭제하지 마세요. 새 버전은 같은 위치의 확장 프로그램 파일을 교체한 뒤 `chrome://extensions`에서 확장 프로그램 새로고침 버튼을 누르고 게임도 새로고침합니다.

`Manifest file is missing or unreadable` 오류가 나오면 선택한 폴더 안에 `manifest.json`이 바로 있는지 확인하세요. 한국어가 적용되지 않으면 설정에서 한국어가 켜져 있는지 확인하고 게임을 새로고침하세요.

Chrome 버전이 낮아 설치할 수 없다는 안내가 나오면 Chrome을 업데이트하세요.

게임 바깥의 사이트, 닉네임과 일부 보스 등장 연출은 원문으로 남습니다. 그 외에 번역이 빠졌거나 어색하다면 [번역 오류를 제보해 주세요](https://github.com/evan-choi/pokesurvivor-kor/issues/new?template=translation.yml).

자세한 설명, 소스 코드와 문제 제보는 [GitHub 저장소](https://github.com/evan-choi/pokesurvivor-kor)에서 확인할 수 있습니다. 라이선스와 제3자 고지는 함께 제공된 `LICENSE`와 `THIRD_PARTY_NOTICES.md`를 참고하세요.
