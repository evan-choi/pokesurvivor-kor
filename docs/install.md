# PokéSurvivor 한국어 모드 설치

1. 설치 ZIP의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 버튼을 누릅니다.
5. `manifest.json`이 바로 들어 있는 폴더를 선택합니다.
6. [게임 페이지](https://pokesurvivor.com/)를 열거나 새로고침합니다.

설치 ZIP은 압축을 풀어 생긴 폴더 자체를 선택합니다. GitHub의 **Code → Download ZIP**으로 저장소를 받았다면 그 안의 `extension/` 폴더를 선택합니다.

처음 설치하면 한국어 모드가 켜집니다. 게임의 **Settings → Graphics → Language**에서 **한국어**를 선택하거나, Chrome 툴바의 확장 프로그램 아이콘에서 켜고 끌 수 있습니다.

## 게임 성능 표시

확장 프로그램 팝업의 **debug** 체크를 켜면 게임 왼쪽 위에 FPS(rAF 기준), 평균·최대 프레임 간격, 50ms 초과 간격 횟수, 긴 작업 시간, 대략적인 JS 힙 사용량이 표시됩니다. 약 1초마다 갱신하며, 한국어 설정과 독립적으로 새로고침 없이 켜고 끌 수 있습니다. 기본값은 꺼짐입니다.

FPS는 브라우저 애니메이션 콜백 빈도이므로 실제 게임이 그린 프레임 수나 화면에 표시된 프레임 수와 다를 수 있습니다. JS 힙은 전체 탭·GPU 메모리가 아닙니다. 이 표시는 GPU 사용률이나 멀티플레이 통신 지연을 측정하지 않습니다. DevTools 성능 녹화, 로그 저장, 외부 전송은 하지 않으며 체크를 끄거나 탭을 숨기면 측정을 중단합니다.

### 멀티플레이 송수신 그래프

debug 아래 그래프는 **최근 30초의 메시지 간격**을 표시합니다. 노란 점선은 이 PC의 송신, 하늘색 실선은 수신입니다. 약 1초마다 해당 구간의 최대 간격을 그리며, 마지막 메시지 이후 기다리는 시간도 포함합니다. 세로축은 자동 조절되므로 왼쪽 위의 ms 값을 함께 보세요. 회색 가로 점선은 300ms 참고선이며, 초과했다고 곧바로 장애를 뜻하지는 않습니다.

선택 메뉴에서 연결과 채널을 바꿀 수 있습니다. 우선 **상태(s)** 채널을 보고, 상태 메시지가 큰 경우 일반 채널로 넘어갈 수 있으므로 **일반(g)**도 확인하세요. 연결 번호는 각 PC의 로컬 번호이며 상대 닉네임이나 양쪽에서 공통으로 사용하는 번호가 아닙니다. 평균 간격과 초당 횟수는 최근 측정 구간 기준, `최대(누적)`는 debug를 켠 뒤 현재 측정 세션의 최댓값, `대기`는 마지막 메시지 이후 시간입니다. `송신 큐`는 아직 전송되지 않고 브라우저에 쌓인 바이트 수입니다. 끄기·탭 숨김 후 다시 켜면 그래프와 최댓값을 초기화합니다.

몬스터가 워프할 때는 방장과 참가자 양쪽에서 확인하세요.

- **방장의 송신 간격도 함께 커짐:** 방장이 상태를 만드는 주기, 게임 일시정지, 송신 큐를 먼저 확인합니다.
- **방장 송신은 일정하지만 참가자 수신이 끊김:** 전송 경로나 참가자 브라우저의 수신 이벤트 처리를 확인합니다. 프레임 간격·긴 작업도 같이 보세요.
- **송수신은 일정한데 몬스터만 워프함:** 게임 메시지 내용이나 위치 보간 처리를 더 조사해야 합니다.

이 그래프는 패킷의 왕복 지연(RTT)이나 서버 처리 시간을 측정하지 않습니다. 송신은 브라우저의 `send()` 호출 성공, 수신은 이 PC의 메시지 이벤트 처리 시각을 기준으로 합니다. 메시지 내용을 해석하지 않으므로 몬스터 상태만 따로 구분하지 않으며, 일반 채널의 원래 드문 메시지·메뉴·일시정지도 큰 공백으로 보일 수 있습니다. 그래프만으로 원인을 확정하지 마세요.

## LAN 직접 연결

같은 집·사무실의 공유기에 연결된 PC끼리 플레이할 때 팝업의 **LAN 직접 연결**을 켜면 중계 전용 제한을 풀어 직접 연결도 허용합니다. 기본값은 꺼짐이며, 켜도 TURN 서버를 대체 경로로 유지합니다. 양쪽 PC에서 옵션을 켠 뒤 방에 다시 참가하세요. 이미 연결된 게임을 끊거나 새로고침하지 않으며, 다음에 만드는 연결부터 적용합니다.

**debug**의 `통신` 항목은 실제 선택된 경로를 표시합니다. `직결`은 TURN 미경유, `TURN`은 중계 경유입니다. 여러 상대와 연결된 방장은 경로별 개수가 함께 표시됩니다. `연결 중`, `연결 끊김`, `확인 불가`, `연결 없음`도 구분합니다. `직결`만으로 같은 LAN 내부 경로임을 보장하지는 않습니다. 공유기의 기기 간 통신 차단이나 방화벽에 따라 같은 공유기에서도 TURN으로 연결될 수 있고, 방장의 처리 지연은 이 옵션으로 해결되지 않습니다.

Radmin VPN 같은 가상 LAN에서도 Chrome이 해당 경로를 선택하면 사용할 수 있지만, 이 옵션은 특정 VPN 사용을 강제하지 않습니다. debug에 `직결`이 표시돼도 VPN 자체는 중계를 사용할 수 있습니다. Radmin의 `Relay/TCP` 여부는 Radmin에서 별도로 확인해야 합니다. 가상 LAN 환경에서의 실제 동작은 아직 검증하지 않았습니다.

## 업데이트와 문제 해결

설치한 폴더는 이동하거나 삭제하지 마세요. 새 버전은 같은 위치의 확장 프로그램 파일을 교체한 뒤 `chrome://extensions`에서 확장 프로그램 새로고침 버튼을 누르고 게임도 새로고침합니다.

`Manifest file is missing or unreadable` 오류가 나오면 선택한 폴더 안에 `manifest.json`이 바로 있는지 확인하세요. 한국어가 적용되지 않으면 설정에서 한국어가 켜져 있는지 확인하고 게임을 새로고침하세요.

Chrome 버전이 낮아 설치할 수 없다는 안내가 나오면 Chrome을 업데이트하세요.

게임 바깥의 사이트, 닉네임과 일부 보스 등장 연출은 원문으로 남습니다. 그 외에 번역이 빠졌거나 어색하다면 [번역 오류를 제보해 주세요](https://github.com/evan-choi/pokesurvivor-kor/issues/new?template=translation.yml).

자세한 설명, 소스 코드와 문제 제보는 [GitHub 저장소](https://github.com/evan-choi/pokesurvivor-kor)에서 확인할 수 있습니다. 라이선스와 제3자 고지는 함께 제공된 `LICENSE`와 `THIRD_PARTY_NOTICES.md`를 참고하세요.
