# 같은 공유기에서 연결하기

모든 PC에 확장을 설치하고 Chrome에서 게임을 엽니다. 각 Windows PC에서 [방화벽 도구 ZIP](https://evan-choi.github.io/pokesurvivor-kor/downloads/pokesurvivor-lan-helper.zip)을 받아 압축을 풉니다.

1. 모든 PC를 같은 공유기의 Wi-Fi나 랜선에 연결합니다.
2. 각 Windows PC에서 `run-as-administrator.cmd`를 우클릭해 **관리자 권한으로 실행**합니다.
3. `1`을 입력합니다. 추천 범위가 현재 Wi-Fi·이더넷의 범위와 같으면 Enter, 다르면 목록의 해당 범위를 입력합니다. Chrome 경로와 범위를 확인하고 `YES`를 입력합니다.
4. 모든 PC에서 게임 **설정 → 네트워크 → P2P 직접 연결**을 **예**로 바꾸고 친구를 초대합니다. 이미 방에 있다면 나갔다 다시 참가합니다.
