# 0.2.23 개인정보 신고 변경안

코드와 개인정보 처리방침에 맞춘 검토안입니다. 스토어 신고는 아직 변경하지 않았습니다. 기존 버전의 공개 신고를 먼저 줄이지 말고, 0.2.23 패키지와 함께 제출합니다.

| 스토어 항목 | 변경안 | 실제 처리와 근거 |
| --- | --- | --- |
| 개인 식별 정보 | 유지 | 번역하는 게임 안내문에 플레이어 닉네임이 포함될 수 있습니다. 별도 사용자 프로필은 만들지 않습니다. 0.2.23부터 보유 목록을 위한 계정 ID 조회는 제거했습니다. |
| 인증 정보 | 해제 | 보유 목록을 읽을 때 Firebase 인증 객체, 로그인 상태, 계정 ID, 세션 식별자, 비밀번호, 토큰을 조회하지 않습니다. |
| 위치 | 유지 | 이미지·티어 요청을 받는 외부 서버와 P2P 연결 상대에게 IP 주소가 전달될 수 있습니다. GPS 조회나 IP 기반 위치 추정은 하지 않습니다. |
| 웹 기록 | 유지 | 팝업에서 현재 열린 게임 탭의 URL과 최근 사용 시점을 확인합니다. 전체 방문 기록을 조회하거나 따로 저장하지 않습니다. |
| 사용자 활동 | 유지 | 툴팁을 표시할 때 게임 안의 현재 커서 위치를 참조합니다. 이동 이력이나 분석 로그를 수집하지 않습니다. |
| 웹사이트 콘텐츠 | 유지 | 화면 문구와 현재 보유 포켓몬 번호를 읽어 번역·표시합니다. |

## 권한 사용 이유

- `storage`: 언어·P2P 설정과 공개 티어 정보의 캐시를 이 브라우저에 저장합니다.
- `scripting`: 열린 게임 탭에서 게임이 현재 불러온 보유 포켓몬 번호만 읽습니다. 계정 식별자, 인증 정보, 저장 파일은 조회하지 않습니다.
- `pokesurvivor.com`, `www.pokesurvivor.com`: 한국어 번역, 전투 표시, 설정과 보유 목록 기능을 제공할 게임 페이지입니다. `/game-auth` 페이지는 주입 대상에서 제외합니다.
- `pokesurvivor.net`: 공개 티어·도감 표를 내려받습니다. 요청에 계정 정보나 보유 목록을 넣지 않습니다.

## 확인한 사항

- `collection.js`는 기존 게임 모듈 포착 코드를 재사용하고 현재 `save.owned`의 키만 반환합니다. 게임 저장 객체 전체나 계정 객체를 팝업에 넘기지 않습니다.
- `owned-pokemon.mjs`는 반환된 포켓몬 번호를 검증합니다. 모듈 구조가 달라졌거나 게임 데이터를 아직 불러오지 못했으면 오류를 표시하며, 이전 계정의 저장 파일을 대신 읽지 않습니다.
- 테스트에서 인증 객체와 저장소 접근이 발생하면 실패하도록 검사합니다. 계정 전환·로그아웃·빈 목록·잘못된 응답도 검증합니다.
- Chrome은 기기 안에서만 처리하는 정보도 공개하도록 안내하므로, 외부 분석 서버가 없다는 이유만으로 모든 항목을 해제하지 않습니다.
